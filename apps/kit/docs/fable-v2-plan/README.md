# Kit v2 plan — folder guide

This folder holds the planning effort for the Kit firmware v2 refactor. It was
produced on 2026-07-31, in one day, by Claude planning agents working under
Jonas's direction — many parallel exploration passes, three independent
architecture candidates, adversarial judging, and live-verified research —
while a separate codex agent was actively implementing v1 in the same
worktree. Ground rules for that day (still binding for anyone editing here):

- This folder is the only writable location for planning work. The codex
  agent's v1 code, its builds, and the physical devices are read-only.
- `apps/kit/docs/physical-device-voice-goal.md` is not edited directly even
  where the plan amends it; amendments are recorded in `DECISIONS.md` for
  Jonas to carry over himself.
- Files under `exploration/` are immutable historical artifacts. They are
  never rewritten; their status lives in the index below.
- Naming rule for everything: plain words, no coined nouns.

**The media transport is two WebSockets.** The device maintains the `/api`
Cap'n Web control WebSocket and the `/pcm` PCM WebSocket at all times — the
same design v1 ships. A WebRTC direction (Opus/UDP via Cloudflare Realtime)
was explored, adopted, and then **cancelled by Jonas on 2026-07-31 after
trying it** (DECISIONS.md §7). Any WebRTC/SFU content anywhere in this
folder is historical research record, not plan.

**The plan is aligned to codex's v1 tree as of the 2026-07-31 evening
recon** (PLAN v1.2; DECISIONS.md §8). The recon files —
`exploration/codex-v1-alignment-firmware.md`,
`exploration/codex-v1-alignment-host.md`,
`exploration/test-dependency-ladder.md` — are its evidence; their numbers
are snapshots of a tree codex was still editing and are re-taken at the G2
checkpoint.

## How to read this folder

1. **`PLAN.md`** — the plan itself, and the only authority on what v2 is.
   Architecture, the decisions it stands on, the staged work order, the
   three-layer testing story, and what "done" means. Always states the
   current plan; no history.
2. **`DECISIONS.md`** — the decision log. Every settled question, what was
   decided, when, and what it replaced — including the goal-doc
   amendments Jonas has made personally and the transport reversal (§7).
   History lives here, not in PLAN.md.
3. **`OPEN-QUESTIONS.md`** — what is still genuinely open, plus the
   validation watchlist.

**A note on push-to-talk.** The final decision of the planning day (G18, the
call interaction model) removed push-to-talk from v2 entirely: the button
connects and hangs up a call, the provider's server-side voice-activity
detection does all turn-taking, and a device-local mute covers talking to
people in the room. Exploration files were written before this. Wherever one
discusses push-to-talk, manual turn commits, commit races, or tail-delivery
guards, read it as historical — that machinery is not built.
