Serving Explainers

An explainer is a single HTML page committed to explainers/ in iterate/iterate. The CI reports viewer, the Worker that already opens CI traces, serves it at any branch or commit, so a pull request can link the explainer on its own branch as soon as it's pushed.

You open
ci-reports asks GitHub for
You get

The rules

  • The page is served as committed. Nothing is built or stored; GitHub serves the public repository's files.
  • A page that isn't at that branch or commit is a 404 that names what was missing. Off main, it links main's copy: a merged pull request's branch is usually deleted.
  • A branch or commit with anything but letters, digits, ., _, - and / is refused before GitHub is asked.
