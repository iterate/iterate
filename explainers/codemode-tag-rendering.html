How a codemode-tag message becomes pixels

Click any event card: it expands to the full event (YAML), and the right pane shows what the chat feed renders as of that offset — computed live by a miniature of the real fold. Dashed purple cards are ephemeral events: real offsets, bodies never stored, delivered only to live subscribers. The src=@N badge is the derivation link: this event was computed from the raw event at offset N.

The opinion — renderers never parse formats; they fold facts. A model's raw output is a fact (exact bytes, prompt-cache identity, replay truth) — but it is written in a format (markdown + one <codemode> tag) that only the project owns. So:
  1. The project's derivation processor is the one parser. The same code that executes a <codemode> block also emits the events renderers show: the prose as web-message-sent, the script as script-run-requested, the status as summary-updated — each stamped with source: {offset}, a top-level envelope field pointing at the raw event it derives from. New format → new processor; zero renderer changes.
  2. Derived events ARE the feed; raw is the fallback. A raw assistant event that something derived from stops rendering as content (its step is "interpreted"; the bubble and script card are the story, Full trace keeps raw reachable). A raw event nothing derives from renders as today — which is also, deliberately, the whole no-backcompat story for old threads and processor-less projects.
  3. The live window derives incrementally over ephemeral events. The token stream already rides ephemeral llm-response-chunks; the processor consumes them (naming the type in consumes — a wildcard never receives ephemeral events) and re-emits ephemeral render/message-delta + render/script-delta. Prose streams as prose, code as code, mid-stream — the tags-on-their-own-line grammar makes the streaming parse a line walk. Nothing durable ever depends on these: the durable facts land at settlement.
Reference — the events, and who writes them
event what it is
agents/context-added Raw model-visible context. The assistant's exact output (the codemode dialect lives in its content), user messages, and developer items (rendered script results, corrective feedback). Written by the platform's agent processor (assistant), members (user), or the derivation processor (developer renders).
agent/llm-response-chunks Ephemeral token stream, ~150ms coalesced flushes, memory-only. Delivered only to subscribers/processors that name it explicitly. The durable truth for its content is the assistant context-added that follows.
render/message-delta · render/script-delta Ephemeral derived deltas from the interpreter's line-buffered partial parse of the chunk stream: cumulative prose-so-far and script-so-far (+ the status label once its opening tag streamed). A dropped delta costs latency, never content. The only new durable-vocabulary opinion the kernel took was… none: durable derived facts reuse platform vocabulary + source.
agents/web-message-sent · agent/summary-updated · capability-host/script-run-requested/-settled The durable derived facts (pre-existing platform vocabulary, now carrying source: {offset} when a derivation processor emits them): the assistant chat bubble, the live activity label, the script execution request and its settlement. The heavy payloads (script body, result) live exactly once — the Script/Result tabs dereference these raw events instead of copying.
render/user-message-described The one new durable derived type (stacked PR): a user message's html attachment parts (<img>/<audio>/<video>/<a>) parsed into {text, attachments} by the reusable user-message-describer facet. The feed re-emits the bubble under its original id; both renderers replace it in place.
source: {offset} The derivation link — third member of the pre-existing top-level source envelope (next to the processor stamp and copiedFrom). A claim, not authentication, like idempotency keys. The reducer marks the step at that offset "interpreted"; feeds sort derived facts where their source sits, so late re-derivation lands in place.
the interpreter facet The codemode-tag template's derivation processor, hosted as a facet of the agent stream's own Durable Object (at-least-once delivery + keepalive — the old project-worker push lane was observation-grade and could silently drop a turn). Same raw idempotency keys as the platform's parser, so birth races dedupe instead of double-executing.
