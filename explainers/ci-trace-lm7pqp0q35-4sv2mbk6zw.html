        Where these timings come from
        

          Workflow and runner attempt times come from Depot. Shell steps have explicit start/exit
          markers. Playwright supplies each attempt’s start time and duration, including fixtures.
          Retries are separate spans. Setup, Wait, Test and Finish are presentation spans derived
          from those boundaries; they include runner and action overhead between measured steps.
        

        

          JavaScript actions (checkout and artifact transfers) do not yet have individual measured
          spans. Their time is included in the enclosing job/phase. A striped span has no completion
          marker; its end is bounded by the runner’s finish and is not an exact observed duration.
          This report does not include request tracing inside deployed workers.
        

        

          The download is an OpenTelemetry ExportTraceServiceRequest JSON object: one trace, stable
          span IDs, parent IDs, nanosecond timestamps and attributes. This page is self-contained
          and can be saved or shared without a tracing service.
