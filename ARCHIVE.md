# Simplification experiment archive

This is the single archive branch for the 2026-09-11 clean-room cleanup:
`backup/v4-celld-2026-09-11`.

It preserves the V4/Celld experiment, the earlier `apps/kernel` implementation,
all `spikes`, the three `packages/v3/project-core*` experiments, and the old
simplification documents and clean-room history at their original paths.
Uncommitted experiment source is included; ignored local runtime data is kept
in a separate local archive rather than Git.

The active clean room is `packages/v3/project-worker`. To resume an archived
experiment, create a separate worktree from this branch.
