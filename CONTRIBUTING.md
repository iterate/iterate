# Contributing

Start with [README.md](README.md) and [AGENTS.md](AGENTS.md). The platform lives in `apps/os`; first-party clients use its OAuth issuer and `iterate/next/*` SDK.

Run the checks relevant to your change from [testing](docs/testing.md). Deployment configuration belongs in `envs.ts`, secrets in Doppler. Follow the [engineering invariant](docs/engineering-invariants.md) and [PR workflow](docs/pull-requests.md).
