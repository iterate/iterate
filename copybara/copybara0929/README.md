# copybara0929

A one-way copy of [iterate/iterate](https://github.com/iterate/iterate)'s `packages/`, made by
[Copybara](https://github.com/google/copybara) after each successful deploy. An experiment:
iterate/iterate#3434.

Don't push or open pull requests here: the next copy overwrites them. Each commit ends in
`GitOrigin-RevId: <sha>`, the iterate/iterate commit it came from.

This README lives in iterate/iterate at `copybara/copybara0929/README.md`.
