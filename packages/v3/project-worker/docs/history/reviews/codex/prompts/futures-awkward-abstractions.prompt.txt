CONTEXT. This package is a clean-room rewrite of Iterate's "iterate context" (itx): one stateless worker (/api, capnweb — Kenton Varda's RPC library, fork @iterate-com/capnweb) proxying over Workers RPC to one SQLite Durable Object per {projectId, path} (IterateContextDurableObject). The DO holds an append-only event log (src/stream/stream.ts), reduces ONE inline core processor at commit (identity, incarnation, paused, the rewrite-rule map, the subscription map — src/stream/core-processor.ts), runs ONE delivery loop after every commit (src/stream/subscription-delivery.ts: push to facets and lent rpc stubs, a stream-kept at-least-once cursor for anything else), hosts loaded DurableObject classes as FACETS (itx.facets.get(name, { source, cacheKey?, className }) → ctx.facets.get) and stateless WorkerEntrypoints (itx.workers.get({ source, cacheKey?, className?, props? })) through the Worker Loader (src/context/worker-loader.ts), lends clients' live rpc stubs via hibernatable "pager" WebSockets (src/context/rpc-stub-directory.ts + rpc-stub-relay.ts) so the DO can hibernate with clients attached, and quiesces idle facets and borrowed stubs on a 60 s alarm. Every dotted call itx.a.b(x) is ONE itx expression (src/context/expression.ts) rewritten through the rule table (src/context/itx-expression-rewriting.ts) to a built-in root (src/context/built-ins.ts) and executed (src/context/dispatch.ts). The edge (src/iterate-context.ts) is a PROXY: cd, invoke, provide(match, stub | expression | null), subscribe, enableProcessor, disableProcessor; every verb builds an event and appends it.
