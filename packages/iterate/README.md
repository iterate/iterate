# Iterate SDK

The SDK for [os-next](../../apps/os-next/README.md). Public entrypoints live under `iterate/next/*`: context APIs, stream processors, reactive clients, React bindings, and OAuth app sessions.

Production issuer: `https://os.iterate2.com`.

```sh
pnpm build
pnpm typecheck
pnpm test
```

The package exports source in this workspace and compiled JavaScript with declarations when packed.
